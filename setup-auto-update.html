🤖 Мастер настройки автообновления пароля

🔄 Проверяем текущую настройку...

Анализируем переменные окружения и готовность системы.

📋 Шаги настройки

1️⃣ Создание Netlify Access Token

Токен необходим для автоматического обновления переменных окружения.

  1. Откройте Netlify Dashboard
  2. Нажмите на аватар → User settings
  3. Выберите Applications → Personal access tokens
  4. Нажмите New access token
  5. Описание: Admin Password Auto Update
  6. Нажмите Generate token
  7. Скопируйте токен (начинается с nfp_)

2️⃣ Получение Site ID

Site ID идентифицирует ваш сайт в Netlify API.

  1. В Netlify Dashboard выберите ваш сайт
  2. Перейдите в Site settings
  3. В разделе Site details найдите Site ID
  4. Скопируйте значение (формат: 12345678-1234-1234-1234-123456789abc)

3️⃣ Установка переменных окружения

Добавляем токен и Site ID в переменные окружения сайта.

  1. В настройках сайта выберите Environment variables
  2. Нажмите Add variable
  3. Добавьте:
    • Key: NETLIFY_ACCESS_TOKEN
    • Value: ваш токен из шага 1
  4. Нажмите Add variable еще раз
  5. Добавьте:
    • Key: NETLIFY_SITE_ID
    • Value: ваш Site ID из шага 2
  6. Нажмите Save

4️⃣ Деплой сайта

Применяем новые переменные окружения.

  1. Перейдите на вкладку Deploys
  2. Нажмите Trigger deploy → Deploy site
  3. Дождитесь завершения деплоя (обычно 1-2 минуты)

🧪 Тестирование

Проверим, что автообновление работает корректно.

🎉 Автообновление настроено успешно!

Теперь при смене пароля в админке он будет автоматически обновляться в Netlify.

✅ Что работает:

  • Автоматическое шифрование паролей (bcrypt)
  • Автоматическое обновление переменной окружения
  • Применение изменений при следующем деплое
